# How I want answers

- Default answer: 3 sentences or 5 bullets at most. No jargon or invented terms; define a needed term in one clause.
- Name concrete things: file:line, endpoint + HTTP method, command.
- Reuse the words we agreed on this session; keep one name per thing.
- More than 3 steps or moving parts: make a small diagram or HTML page instead of prose.
- When I ask "is that correct?", answer yes/no first, then one line of why.
- Proceed on reversible steps without asking. Post comments, merge, or delete remote branches only when I asked for it.

# Pointers

- Skills are authored in `~/.dotfiles/home/.agents/skills/<name>/SKILL.md` (see `~/.dotfiles/home/.agents/README.md`); after adding or renaming one, run `skills sync claude-code claude-work`. Commit a SKILL.md before rewriting it.
